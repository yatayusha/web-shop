# web-shop

Интернет-магазин, где пользователь может просматривать каталог товаров, добавлять их в корзину и управлять покупками.

## Реализованная логика

- Реализация добавления товара в корзину при нажатии на кнопку с подсчетом суммы товаров в корзине
- Реализация удаления товара из корзины
- Реализация изменение количества товара в корзине, сумма автоматически пересчитывается и данные обновляются в localStorage.
- Сохранение корзины в localStorage при обновлении страницы
- При нажатии кнопки «Создать заказ» показывается сообщение «Заказ создан!»
- С пустой корзиной невозможно перейти к оформлению заказа
- С незаполненными полями (имя, номер, адрес) невозможно создать заказ

## Макет и верстка
- Создана HTML-страница магазина с карточками товаров, названием, ценой и кнопками «Добавить в корзину» 
- Использована семантическая разметка 
- Форма содержит все обязательные поля: имя, фамилия, адрес доставки, контактный номер телефона и кнопку «Создать заказ»
- Использованы CSS: flex/grid
